### UI要素

| No. | 要素名 | 種別 | 表示内容・仕様 |
|-----|--------|------|----------------|
| **1** | NavigationBar タイトル | テキスト | 「VocaVault」。右端に「フォルダ追加（＋）」ボタン |
| **2** | 今日の復習サマリーカード | カードView | 表示パターンを3段階に分岐する。①復習対象あり：「今日の復習：○語」「予想時間：約○分」を表示。タップでS04へ遷移（全フォルダ対象）。②復習対象0件・Newカードあり：「新しい単語を学習しましょう（○語）」とラベルを変更してタップ有効のままにする。**予想時間は表示しない。** タップでS04へ遷移（Newカードのみセッション）。③復習対象0件・Newカードも0件：「今日の復習はありません」と表示し、タップを無効化する。 |
| **3** | ストリーク表示 ★ | テキスト＋アイコン | 以下の3パターンで表示を切り替える。**①連続学習中**（streakDays≥1・isBroken=false）：「🔥 ○日連続学習中！」形式で表示。**②ストリークが途切れた場合**（前日に学習記録なし・isBroken=true）：「昨日は学習をお休みしました。今日から再開しましょう！」バナーに切替表示。**③初回利用時・学習履歴0件**（streakDays=0・isBroken=false）：「最初の学習を始めましょう！」のガイドテキストを表示。（F33準拠） |
| **4** | フォルダ一覧 | List | 登録済みフォルダをカード形式で一覧表示。フォルダ名・総単語数・今日の復習数を各カードに表示。 |
| **5** | フォルダカード | Card View | フォルダ名・総単語数・今日の復習数を表示。タップでS02へ遷移。 |
| **6** | フォルダ追加（＋） | ボタン | NavigationBarの右端。タップでフォルダ名入力のAlertを表示。 |
| **7** | フォルダ編集・削除 | スワイプアクション | フォルダセルを左スワイプで「編集」「削除」。削除時は確認ダイアログを表示。 |

| 種別 | 内容 |
|------|------|
| **フォルダが0件の場合** | 「フォルダがありません。＋ボタンで追加してください」のEmptyStateViewを表示。 |
| **サマリーカードの3段階分岐** | ①全フォルダ合算でdueDate≤今日のカードが1件以上存在→「今日の復習：○語」「予想時間：約○分」を表示、タップ有効。②①のカードが0件かつ全フォルダ合算でstate=Newのカードが1件以上存在→「新しい単語を学習しましょう（○語）」を表示、タップ有効。**予想時間は表示しない。** ③①②どちらも0件→「今日の復習はありません」を表示、タップ無効化。 |
| **ストリーク計算** | ReviewLogに当日の記録がある日を学習日とし、途切れのない連続日数をカウント。タイムゾーンはデバイスローカル基準。（F33準拠） |
| **予想時間の算出** | 復習対象単語数 × 30秒 ÷ 60。端数切り上げ。**Newカードのみセッション時は予想時間を算出・表示しない。**（F33準拠） |
| **フォルダ名バリデーション ★** | フォルダ追加（操作#3）・フォルダ編集（操作#4）時のフォルダ名バリデーション仕様（最大50文字・重複チェック等）はS03制約を参照。 |
